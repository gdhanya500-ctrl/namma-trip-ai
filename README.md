# 🧭 NammaTrip AI – Smart Karnataka Travel Planner

### Discover Karnataka. Plan Smarter. Travel Better.

NammaTrip AI is a smart travel planning application designed to help users explore destinations across Karnataka, India. It helps travelers discover places based on their interests, organize destinations into a multi-day itinerary, and estimate their travel budget in one convenient interface.

## 🌟 Key Features

* **🗺️ Personalized Recommendations:** Discover destinations based on your selected interests and preferred region.
* **📅 Smart Itinerary Planner:** Organize recommended destinations across multiple days based on estimated visiting hours.
* **💰 Budget Estimator:** Estimate travel expenses, including accommodation, food, transportation, entry fees, and contingency costs.
* **🏞️ Destination Explorer:** Explore destinations with descriptions, categories, visiting hours, and estimated entry fees.
* **🗣️ Kannada Travel Phrases:** Access useful Kannada phrases for communicating during your trip.
* **📥 Downloadable Itinerary:** Download your planned itinerary as a CSV file.
* **💻 Simple Interface:** Use an easy-to-navigate interface built with Streamlit.

## 🎯 Problem Statement

Planning a trip involves researching destinations, organizing daily activities, estimating expenses, and finding places that match individual interests. These tasks can be time-consuming, especially for travelers unfamiliar with Karnataka.

NammaTrip AI aims to simplify this process by bringing destination discovery, itinerary organization, and budget estimation together in one application.

## 💡 Our Solution

NammaTrip AI provides a centralized travel planning experience that helps users:

1. Select their travel interests.
2. Discover suitable destinations in Karnataka.
3. Organize destinations into a multi-day itinerary.
4. Estimate the overall trip budget.
5. Explore useful Kannada travel phrases.
6. Download itinerary information for future reference.

## ⚙️ Installation and Setup

Follow these steps to run NammaTrip AI on your computer.

### Prerequisites

* Python 3.10 or a compatible newer version
* pip package manager
* Git (optional)

### Step 1: Clone the repository

```bash
git clone https://github.com/gdhanya500-ctrl/namma-trip-ai.git
```

### Step 2: Open the project folder

```bash
cd namma-trip-ai
```

### Step 3: Install dependencies

```bash
pip install -r requirements.txt
```

### Step 4: Run the application

```bash
python -m streamlit run app.py
```

The application will open in your browser. If it does not open automatically, visit:

`http://localhost:8501`

## 💰 Budget Estimation

The application estimates trip expenses using configurable assumptions for:

* Accommodation
* Food
* Transportation
* Destination entry fees
* Additional contingency expenses

**Note:** Budget figures are estimates for planning purposes and may differ from actual travel expenses.

## 🧠 Recommendation Approach

The current prototype uses a rule-based recommendation approach. It compares users' selected interests with destination categories in the dataset and ranks destinations according to matching interests.

The itinerary planner distributes destinations across the selected number of days using estimated visiting hours.

## ⚠️ Current Limitations

* Recommendations depend on the available destination dataset.
* Travel routes and road distances are not calculated in the current prototype.
* Budget estimates are not live market prices.
* Recommendations are rule-based rather than generated by an AI model.
